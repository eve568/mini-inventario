# Mini Inventario

Mini Inventario es una web de inventario.
El proyecto usa Node.js 22 y Python 3.12.
Cada cambio debe hacerse en una rama y entregarse mediante un pull request.
Nunca subir llaves, credenciales ni archivos .env al repositorio.
Pedir aprobación explícita antes de borrar datos.
Pedir aprobación explícita antes de desplegar.
